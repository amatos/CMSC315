\section{Design}
The goal of the project was to understand in depth how Java handles binary trees
and their usage. Binary trees are critical data structures for efficient
searching and sorting of data. While Java implements common methods for
interacting with binary trees, this project walked us through implementing
our own methods, with a goal of better understanding what the core java
methods are doing.

\section{Lessons Learned}
During the course of this project, this programmer did not experience any
significant challenges, beyond careful reading of the project requirements,
and thinking about how to properly implement tasks 3 (if a tree is a max-heap)
and task 4 (check if a complete binary tree is a binary search tree).

An error was originally made in task 3 that did not show up until I was trying
to implement task 4, specifically in identifying a binary tree that is a max-heap,
but is not a binary search tree.  The cause of the error was that I had not taken
into consideration that I might have a valid max-heap that contained a proper
value in the left node, but did not contain any value in the right node.  My
code was initially calling it not a max-heap, and it had passed my initial
implementation tests.  However, when I ran the scenario presented in the
project instructions, specifically, a binary tree consisting of
\enquote{20 18 15 10}(see \ref{fig:max-heap-not-bst}), I kept getting a result that the tree was \emph{not}
a max-heap, even though it \emph{should} have been.

I addressed this issue by more carefully determining whether a binary tree
is max heap by considering the case of when a parent only has a single child
node in the tree.
